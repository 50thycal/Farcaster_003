# PR-004 — Minimal Frame (Cast Lookup Tester)

Adds a Farcaster Frame that demonstrates cast lookup functionality in Warpcast.

## Changes

**app/frame/route.ts** (new)
- GET handler: Initial frame view with input field
- POST handler: Processes user input and validates cast
- Uses existing `/api/casts/[hash]` endpoint
- Returns success/error image based on cast lookup result
- Supports both Warpcast URLs and raw cast hashes

**app/api/og/route.tsx** (new)
- Dynamic OG image generator using Next.js ImageResponse
- Runs on edge runtime for fast image generation
- Accepts `title` and `subtitle` query params
- Returns 1200x630 PNG images for frame displays

**app/page.tsx**
- Added 4th card linking to `/frame`
- Updated grid to support 4 columns (responsive)

**.env.example**
- Added `APP_BASE_URL` configuration
- Required for absolute URLs in frame meta tags

## What is a Farcaster Frame?

Frames are interactive mini-apps that work inside Farcaster casts (posts). When you share a frame URL in Warpcast, it renders as an interactive card with buttons, inputs, and images.

This frame demonstrates:
- Input field for cast URL/hash
- Submit button to validate cast
- Dynamic response images (success/error)
- "Try another" button to restart

## Problem Solved

Provides a working example of Farcaster Frame development using the existing free-tier API endpoints. Demonstrates how to:
- Build Frame GET/POST handlers
- Generate dynamic OG images
- Parse frame input from Warpcast
- Call internal API routes from frames
- Handle errors gracefully in frame context

## User Flow

1. User posts frame URL in Warpcast: `https://your-app.vercel.app/frame`
2. Frame renders with input field: "Warpcast URL or hash"
3. User pastes cast URL (e.g., `https://warpcast.com/username/0x123`)
4. Clicks "Submit" button
5. Frame validates via `/api/casts/[hash]`
6. Shows result:
   - ✅ "Cast found" (green image)
   - ❌ "Cast not found" with error message

## Acceptance Criteria

✓ `/frame` returns HTML with frame meta tags
✓ POST to `/frame` with input returns new frame state
✓ `/api/og` generates dynamic PNG images
✓ Frame works in Warpcast when cast URL is shared
✓ Input parsing handles both URLs and raw hashes
✓ Error messages are clear and helpful
✓ Build succeeds with edge runtime warning (expected)

## Setup Instructions

Add to Vercel and `.env.local`:

```bash
APP_BASE_URL=https://your-app.vercel.app
```

Note: No trailing slash!

### 2. Deploy

Push to Vercel and it will auto-deploy.

### 3. Test in Warpcast

1. Open Warpcast mobile app or web
2. Create a new cast
3. Paste your frame URL: `https://your-app.vercel.app/frame`
4. The frame should render with input field
5. Test with a valid Warpcast cast URL

## Technical Details

**Frame Protocol:**
- Uses Farcaster Frame v2 spec (`fc:frame` meta tag)
- Input captured via `fc:frame:input:text`
- POST data in `untrustedData.inputText`

**Image Generation:**
- Next.js `ImageResponse` API (built-in)
- Edge runtime for low latency
- 1200x630 dimensions (Farcaster standard)

**API Integration:**
- Calls `/api/casts/[hash]` internally
- Uses existing Neynar integration
- Works on free plan (exact cast lookup)
