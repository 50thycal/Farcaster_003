# PR-002 — Neynar Client + Zod Contracts

Implements Neynar API integration with Zod validation and wires all API routes to return real data.

## Changes

**lib/neynar.ts**
- Thin wrapper around Neynar API v2
- Handles authentication with NEYNAR_API_KEY
- Error handling with status code propagation
- Cache control for fresh data

**lib/schemas.ts** (new)
- Zod schemas for ProfileLite, Cast, and Graph responses
- Validates Neynar API responses
- Flexible schemas for varying API payloads

**lib/fetchers.ts** (new)
- `searchUsers(q, cursor)` — Search users with pagination
- `getCastByHash(hash)` — Fetch cast by hash
- `getFollowers(fid, cursor)` — Get followers list
- `getFollowing(fid, cursor)` — Get following list
- Normalizes Neynar responses to app types

**API Routes Updated**
- `/api/users/search` — Real user search with pagination
- `/api/casts/[hash]` — Real cast lookup by hash
- `/api/graph/followers` — Real followers list with pagination
- `/api/graph/following` — Real following list with pagination

## Acceptance Criteria

✓ Vercel build succeeds without errors
✓ API routes return real data from Neynar
✓ Pagination cursors work for search and graph endpoints
✓ Error handling with appropriate status codes
✓ UI pages automatically render live data

## Testing

Set `NEYNAR_API_KEY` in environment variables, then:

```bash
# Search users
curl "http://localhost:3000/api/users/search?q=v"

# Fetch cast (use valid hash)
curl "http://localhost:3000/api/casts/<hash>"

# Get followers
curl "http://localhost:3000/api/graph/followers?fid=3"

# Get following
curl "http://localhost:3000/api/graph/following?fid=3"
```
